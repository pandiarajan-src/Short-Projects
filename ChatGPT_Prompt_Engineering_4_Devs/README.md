# ChatGPT Prompt Engineering for Developers

Worked through the [deeplearning.ai](https://www.deeplearning.ai) short course ["ChatGPT Prompt Engineering for Developers"](https://learn.deeplearning.ai/courses/chatgpt-prompt-eng/). One notebook per lesson, learning how to work with prompts using OpenAI APIs.

## Lessons

- `l2-guidelines.ipynb` — guidelines for prompting
- `l3-iterative-prompt-development.ipynb` — iterative prompt development
- `l4-summarizing.ipynb` — summarizing
- `l5-inferring.ipynb` — inferring
- `l6-transforming.ipynb` — transforming
- `l7-expanding.ipynb` — expanding
- `l8-chatbot.ipynb` — building a chatbot

## Setup

```bash
pip install openai
```

Set your OpenAI API key, then open the notebooks in lesson order.
