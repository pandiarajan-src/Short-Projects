# Flashcards skill

Follow these steps when making flashcards:

1. **Gather facts.** If the student gave a topic but no material, research it first
   (use web search) and keep only facts you can back with a source.
2. **Write 5 cards** unless the student asks for a different number. Each card:
   - **Q:** one question, under 15 words, testing a single idea
   - **A:** the answer, under 25 words
3. **Mix the card types:** at least one definition, one "why" question, and one example.
4. **Save every card** with the `add_note` tool, using the topic name as `topic` and
   `Q: ... | A: ...` as `content`.
5. **Show the cards** to the student as a numbered list, then list your sources.

Never invent facts. If a fact can't be verified, leave that card out.
