# LangChain for LLM Application Development

Worked through the [deeplearning.ai](https://www.deeplearning.ai) short course ["LangChain for LLM Application Development"](https://learn.deeplearning.ai/courses/langchain/). One notebook per lesson, understanding the powerful and extensible LangChain framework with prompts, parsing, memory, chains, question answering, and agents.

## Lessons

- `L1-Model_prompt_parser.ipynb` — models, prompts and parsers
- `L2-Memory.ipynb` — chat memory
- `L3-Chains.ipynb` — chains (uses `L3-Data.csv`)
- `L4-QnA.ipynb` — question answering over a catalog (uses `L4-OutdoorClothingCatalog_1000.csv`)
- `L5-Evaluation.ipynb` — evaluation
- `L6-Agents.ipynb` — agents

The folder also contains `.jpeg` screenshots from the course.
