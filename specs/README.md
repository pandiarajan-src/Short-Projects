# Specs

This is a directory for test plans — markdown plans produced by the
`playwright-test-planner` agent before any spec code is written (see the
root [README.md](../../README.md) for the Plan → Generate → Heal workflow).

It is currently empty: once plans exist, each is a `.md` file describing
the scenarios, steps and expected outcomes for the generator agent to turn
into `*.spec.ts` files under [`../tests/`](../tests/).
