# MCP: Build Rich Context AI Apps

Worked through the [deeplearning.ai](https://www.deeplearning.ai) short course ["MCP: Build Rich Context AI Apps"](https://www.deeplearning.ai/short-courses/mcp-build-rich-context-ai-apps/). One notebook per lesson, learning the Model Context Protocol (MCP) — the open standard for connecting AI assistants to the systems where data lives.

## Lessons

- `L3-Chat Example.ipynb` — a chat example
- `L4-Creating MCP Server.ipynb` — creating an MCP server
- `L5-Creating MCP Client.ipynb` — creating an MCP client
- `L6-Connecting MCP Chatbot to Ref Servers.ipynb` — connecting a chatbot to reference servers
- `L7-Adding Prompt and Resource Features.ipynb` — prompt and resource features
- `L9-Creating and Deploying Remote Servers.ipynb` — creating and deploying remote servers
- `Appendix-2.ipynb` — appendix

Supporting files: `References/` and `requirements.txt`.
