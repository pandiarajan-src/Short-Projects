# Generative AI with LLMs (AWS)

Worked through the [deeplearning.ai](https://www.deeplearning.ai) short course ["Generative AI with LLMs"](https://www.deeplearning.ai/courses/generative-ai-with-llms/), created in collaboration with AWS. A great start to learning Generative AI with good examples in an AWS environment.

## Labs

- `Lab_1_summarize_dialogue.ipynb` — dialogue summarization with LLMs
- `Lab_2_fine_tune_generative_ai_model-Initial.ipynb` — fine-tuning a generative AI model (initial version)

Supporting folders: `data/` and `images/` used by the labs.
